Purified Water Line Controller

OpenComputers master control for the Water Purification Plant

← All tools · Source on GitHub · Original by 夙棠 (sutang)

Schedules all eight purification grades by priority (lowest first, so feedstock never starves), runs multiple grades concurrently to saturate your energy hatch, and shows a live dashboard: stocks, targets, parallels, power draw, success rates. English translation of sutang's v4.4 with extras: click-to-edit stock targets (popup editor on the dashboard), a targets.lua config mode that needs no ME Level Maintainer, honest voltage display, and plain 2A energy hatch support.

Requirements

  • GTNH 2.7.4+; an OC computer (tier 3 screen recommended) with an Internet Card, a Redstone Card, and a Keyboard on the screen.
  • Adapters (with MFUs where blocks are remote) connecting: the Water Purification Plant controller, its energy hatch(es), the water subnet's dual item+fluid interface, and every purification unit controller. Optional: an ME Level Maintainer for stock targets (otherwise use targets.lua or the popup editor).
  • A redstone line from the computer (default: west face) to a Machine Controller cover on the plant, set to enable-with-redstone.

Install

In the OC shell. The installer fetches the latest release, pinned by commit so downloads are never stale; re-running it updates in place and preserves your targets.lua.

First start

  1. Check the dashboard lists every machine as connected (the [Scan] log line counts them).
  2. Set stock targets: click a grade's target number on the dashboard (popup editor: digits, k/m suffixes, Enter saves, click away cancels, 0 disables) — or configure rows in the ME Level Maintainer if you use one.
  3. Click each grade in the parallels panel and set per-machine parallels (a suggestion based on your energy hatch is shown).
  4. Start the system and switch on the plant controller. Watch one 120 s cycle.

Good to know

Full ProductionInverts priority to grade 8 first, ignores stock targets — emergency burst mode. Borders turn red while active; it's a toggle.
New unitsRun one manual cycle on a freshly built high-grade unit before connecting it to OC.
ProtectionsAuto-stop on power failure; production halts at 5× target so storage never floods.
Wireless mirrorState broadcasts on port 13579 — a second computer with a wireless card can run a read-only dashboard.
Keyboard inputTyping requires the screen GUI open (right-click the screen) and a Keyboard attached to that screen.
